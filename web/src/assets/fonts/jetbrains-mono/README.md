# JetBrains Mono

JetBrains Mono is designed by JetBrains and distributed under the
[SIL Open Font License 1.1](./OFL.txt). The license permits embedding and
redistribution with applications, including commercial applications, provided
the copyright notice and license accompany the font.

This directory contains the unmodified regular webfont from the official
JetBrains Mono 2.304 release:

- Source: https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304
- File: `fonts/webfonts/JetBrainsMono-Regular.woff2`
- Local name: `jetbrains-mono-400.woff2`

The font is vendored so the Console renders consistently in self-hosted and
air-gapped serverSENTINEL deployments without a third-party font CDN.
