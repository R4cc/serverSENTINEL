# Switzer

Designed by Jérémie Hornus and the Indian Type Foundry (ITF), released through
Fontshare under the **ITF Free Font License**, which permits personal and
commercial use, including embedding in web pages and applications.

- Foundry: Indian Type Foundry — https://www.indiantypefoundry.com
- Distribution: https://www.fontshare.com/fonts/switzer
- License terms: https://www.fontshare.com/licenses/itf-ffl

The files in this directory are the unmodified web (`.woff2`) builds served by
Fontshare, limited to the three weights the interface uses:

| File                | Weight | Style  |
| ------------------- | ------ | ------ |
| `switzer-400.woff2` | 400    | normal |
| `switzer-500.woff2` | 500    | normal |
| `switzer-600.woff2` | 600    | normal |

They are vendored rather than loaded from the Fontshare CDN so that the
application has no runtime third-party dependency and renders identically in
air-gapped and self-hosted deployments.
